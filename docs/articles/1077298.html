Basic hygiene when working with AI

Let's start with the harsh truth: it's impossible to completely avoid the risk of data leakage when working with popular publicly available models (ChatGPT, GigaChat, Gemini, etc.), this is a fact. At the very least, conversations in AI chats are checked for ethics and safety. They are scanned by automatic filters, and some dialogues are manually checked by employees and contractors of the model providers. In addition, in corporate accounts, the history can be viewed by the organization's administrators, and in some cases, by law enforcement agencies upon request.

Here's the absolute minimum you can do to avoid leaking your data to AI.

Disable data transfer so the model doesn't learn from your conversations
How to do this step-by-step is described below. It's important to say here that this action only applies to the future, meaning information from old chats may have already been used to retrain the neural network. Another point: if you've connected, for example, some messenger to the model, you also need to disable personal data transfer there. You should also keep an eye on user agreement updates, as things can change at any moment.

Mask your data
Replace confidential data with placeholders like {phone number}, {name}, etc. If you have a lot of data and don't want to process it manually, there are ready-made tools to automate this task, such as Redacto or Garda Masking. However, in this case, you need to remember that the result must still be checked manually, because the algorithm can make mistakes: miss a value, incorrectly identify the data type, or replace something wrong altogether.

Delete chats and start new sessions
The longer the conversation, the more related private information remains in the model's cache. In case of a leak or account hack, attackers will get a huge amount of data about you, your project, or your codebase. Therefore, it's important to regularly delete old chats and open fresh sessions for new tasks.

To avoid having to reconfigure the AI for yourself every time, specify the desired behavior of the neural network directly in the first prompt. And in some services, like Gemini or ChatGPT, you can create a custom bot with pre-configured instructions once, which will save you from having to specify the behavior and train the model in dialogues.

Beware of vulnerabilities
When downloading models from open sources, such as Hugging Face, make sure there are no malicious injections in files like .pkl.

A malicious injection, in simple terms, is a virus embedded in the model. To check if everything is clean, you can use utilities, for example, Model Scanner from HiddenLayer.

Also, try to download popular models from well-known authors to avoid hidden data collection and network requests.

Check what you send to the model
If you take a ready-made prompt from some website, you should be prepared for an unpleasant surprise: a dangerous command might be hidden somewhere in the middle of a long prompt or be invisible at all because it's colored the same as the page background. Therefore, it's better to first copy the prompt into Word and apply one color to the entire text – then all that is hidden will become apparent.

Thoroughly check the AI generation results
If you need to generate an image, for example, for advertising, make sure it doesn't contain characters, symbols, or logos for which someone already holds copyright. That is, you cannot ask the AI to depict Nintendo characters, because Nintendo has the right to claim its rights. You should check the generation result through an image search on Yandex or Google.

It's important to understand that copyright in the AI sphere is not simple at all; my colleague from the legal team discussed this problem in more detail in this article.

These recommendations should be enough to get started :) If you know any other useful settings, please write in the comments.

How to disable data transfer in free models

Spoiler: absolutely all models use dialogues for training, but not all models allow you to restrict data transfer.

Here is a list of the most popular providers and mini-instructions for them.

OpenAI (ChatGPT)

Are data used for model training — yes.

How to disable data transfer
Go to Settings —> Data Controls and turn off the "Improve the model for everyone" option.

As a last resort, you can write directly to the company with a request to delete information about your transmitted data in chats. Although I don't know of any real cases where someone has done this, according to the ToS, information about you should not be transferred, but moderators will still have access.

Google (Gemini)

Are data used for model training — yes.

How to disable data transfer
You can restrict data transfer by disabling chats, but then all dialogues will be automatically deleted 72 hours after creation, and old chats created before setting the restriction will continue to be used - it's better to delete them manually.

Go to Settings —> History (in the mobile app, it's the next item) —> Gemini App Activity History —> turn off the option.

DeepSeek

Are data used for model training — yes.

How to disable data transfer
Go to Settings —> Data —> turn off the "Improve the model for everyone" option.

The same story here with old chats - even with data transfer turned off, they will be available for moderation by the model developer for several days.

Anthropic (Claude)

Are data used for model training — yes.

How to disable data transfer
Go to Settings —> Privacy section —> turn off two options: Location Metadata and Help improve our AI models.

In Claude, old chats, after disabling data transfer, will not be available for model training if this process has not already started. But they will be available for moderation.

Sber (GigaChat)

Are data used for model training — yes.

How to disable data transfer
In the web chat and mobile app, there's no way 😊

Yandex (Alice AI)

Are data used for model training — yes.

How to disable data transfer
You need to go to Yandex ID, because you can't disable data transfer directly from the app. The path is: Security —> Access Management —> Alice —> disable the "Help Alice get better" option.

Local launch. The safest model is on your computer

Deploying a model locally on your own PC or server on some hosting is the safest option, although there are also pitfalls here.

Preparation

To run a model on your PC, you'll need Ollama (there are other software options, but it's one of the most popular). It has documentation on how to install and add the necessary models. A wide selection of models is offered for download by default. Ollama supports models that have a GGUF version; you can download them from the Hugging Face library; they are also considered the safest.

With the model deployed, you can interact with it through a chat interface like any chatbot. When the application starts, a server is also launched, which can be specified in any AI client to connect the model to that client.

It's important to note that running a model locally requires significant computing power, and a separate server is even better, which you can, for example, rent in the cloud.

It's also good practice to run the model in a separate Docker container for even greater isolation of the AI from your PC.

Download Ollama and open the application.

Let's summarize

Free neural networks are a convenient and accessible tool, but for this freeness, we pay with our data, and sometimes with data and money. All major providers (both foreign and domestic) use our data to train models. The ability to completely disable data transfer is available for many, but not all. And even where this option exists, the data still goes for moderation or is stored in logs.

It is impossible to completely eliminate the risk of data leakage when working with models. But it can be minimized: use placeholders instead of real data, regularly clear chats, check downloaded models for malicious injections, and carefully read what you send to the model.

The most private option is to deploy the model locally via Ollama (preferably in a Docker container). But it requires computing power and some technical preparation.

If you require confidentiality, build your own AI client (like ChatBox) with a paid API key, run the model locally or on a dedicated server. And if you use free services, follow basic digital hygiene rules and remember: your data is your responsibility.
